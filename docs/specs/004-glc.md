# Spec 004 — Gramática Livre de Contexto (GLC)

| Campo      | Valor |
|------------|-------|
| Status     | ⏳ Pendente (não iniciado) |
| Módulo     | Módulo 3 do enunciado |
| Endpoint   | `POST /api/glc` (proposto) |
| Aba        | `4. GLC` (proposta) |

> Spec em rascunho para guiar quem for implementar. Siga o passo a passo em [`docs/COMO-ADICIONAR-MODULO.md`](../COMO-ADICIONAR-MODULO.md).

## 1. Objetivo
Definir G = (V, T, P, S), dizer se uma cadeia é gerada por G, mostrar a derivação passo a passo
e uma árvore de derivação simplificada.

## 2. Requisitos (do enunciado)
- [ ] Definir variáveis (V)
- [ ] Terminais (T)
- [ ] Produções (P) — ex.: `S -> aSb`, `S -> λ`
- [ ] Símbolo inicial (S)
- [ ] Derivação passo a passo
- [ ] Árvore de derivação simplificada
- [ ] Exemplo: `S -> aSb | λ`, entrada `aaabbb` → **Aceita**

## 3. Entradas propostas
```json
{
  "variaveis": ["S"], "terminais": ["a","b"], "simboloInicial": "S",
  "producoes": [ {"esquerda":"S","direita":"aSb"}, {"esquerda":"S","direita":"λ"} ],
  "cadeia": "aaabbb"
}
```

## 4. Algoritmo sugerido (simples)
Busca em largura por **derivações mais à esquerda**: fila de formas sentenciais começando em `S`;
troca a variável mais à esquerda por cada lado direito possível; descarta formas cujo prefixo
de terminais não bate com a cadeia ou cujo nº de terminais passa de |w|; limite de passos (ex.: 10 000).
Guardar o "pai" de cada forma para reconstruir a derivação e a árvore.
(Alternativa mais robusta: CYK, exige converter para Forma Normal de Chomsky.)

## 5. Saída proposta
`aceita`, `mensagem`, `derivacao` (`S ⇒ aSb ⇒ aaSbb ⇒ aaaSbbb ⇒ aaabbb`), `arvore` (nós com filhos).

## 7. Complexidade (a preencher)
BFS: exponencial no pior caso (limitada pelo nº de passos). CYK: Θ(n³·|P|).
