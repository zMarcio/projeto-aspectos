# Spec 002 — Autômato Finito Determinístico (AFD)

| Campo      | Valor |
|------------|-------|
| Status     | ✅ Implementado |
| Módulo     | Módulo 2 do enunciado |
| Endpoint   | `POST /api/afd` |
| Aba        | `2. AFD` |

## 1. Objetivo
Definir um AFD M = (Q, Σ, δ, q0, F), carregá-lo por JSON, executar uma cadeia e mostrar
o passo a passo das transições, dizendo se a cadeia é ACEITA ou REJEITADA.

## 2. Requisitos (do enunciado)
- [x] Estados (Q)
- [x] Estado inicial (q0)
- [x] Estados finais (F)
- [x] Função de transição δ: Q × Σ → Q
- [x] Carregar um autômato por JSON (botão "Abrir JSON…" na aba e corpo da API no mesmo formato)
- [x] Executar uma cadeia
- [x] Mostrar passo a passo (`q0 -> q1 -> q2` + tabela + navegação ⏮ ◀ ▶ ⏭ com os estados desenhados)

## 3. Entradas (formato do JSON — o mesmo do arquivo salvo/aberto na aba)
| Campo | Tipo | Obrigatório | Exemplo |
|-------|------|-------------|---------|
| `estados` | lista | sim | `["q0","q1","q2"]` |
| `alfabeto` | lista | sim | `["a","b"]` |
| `estadoInicial` | texto | sim | `"q0"` |
| `estadosFinais` | lista | não (vazio = nunca aceita) | `["q2"]` |
| `transicoes` | lista de `{origem, simbolo, destino}` | sim (≥1) | `[{"origem":"q0","simbolo":"a","destino":"q1"}]` |
| `cadeia` | texto | não (vazio/`λ` = cadeia vazia) | `"ab"` |

Na aba, as transições são digitadas uma por linha: `q0 a q1` (também aceita `q0, a, q1`).

## 4. Regras e validações
- Estado repetido, símbolo repetido, símbolo com >1 caractere, `λ` no alfabeto → erro 400.
- Estado inicial/final/origem/destino que não está em Q → erro 400.
- Símbolo da transição fora de Σ → erro 400 (logo `λ` não é permitido no AFD).
- **Determinismo**: o mesmo par (origem, símbolo) duas vezes → erro 400 sugerindo a aba AFN.
- AFD **parcial** é permitido: se faltar δ(q, a) durante a execução, a cadeia é **rejeitada** (não é erro).
- Símbolo da cadeia fora de Σ → **rejeita** (não é erro).

## 5. Algoritmo
```
atual = q0; caminho = [q0]
para cada símbolo s da cadeia:
    se s ∉ Σ: REJEITA
    destino = δ[atual|s]          // HashMap com chave "estado|símbolo"
    se não existe: REJEITA
    registra passo (atual, s, destino, o que falta ler)
    atual = destino
ACEITA se atual ∈ F, senão REJEITA
```

## 6. Contrato da API
Requisição (`exemplos/afd-enunciado.json`, exemplo do enunciado):
```json
{
  "estados": ["q0","q1","q2"], "alfabeto": ["a","b"], "estadoInicial": "q0", "estadosFinais": ["q2"],
  "transicoes": [ {"origem":"q0","simbolo":"a","destino":"q1"}, {"origem":"q1","simbolo":"b","destino":"q2"} ],
  "cadeia": "ab"
}
```
Resposta:
```json
{
  "aceita": true,
  "mensagem": "Parou em q2, que é estado final. ACEITA",
  "caminho": "q0 -> q1 -> q2",
  "estadoFinal": "q2",
  "passos": [
    {"numero":1,"estado":"q0","simbolo":"a","destino":"q1","restante":"b"},
    {"numero":2,"estado":"q1","simbolo":"b","destino":"q2","restante":""}
  ]
}
```

## 7. Complexidade
n = |w|, |δ| = nº de transições.

| Operação | Melhor (Ω) | Médio (Θ) | Pior (O) |
|----------|-----------|-----------|----------|
| Montar δ (HashMap) | Ω(\|δ\|) | Θ(\|δ\|) | O(\|δ\|) |
| Executar cadeia | Ω(1) — 1º símbolo sem transição | Θ(n) | O(n) — cada passo é uma consulta O(1) no HashMap |

## 8. Critérios de aceite (testes em `AfdTest`)
- [x] Exemplo do enunciado, `ab` → ACEITA, caminho `q0 -> q1 -> q2`, 2 passos
- [x] `a` → REJEITA (parou em q1, não final)
- [x] `abb` → REJEITA (sem δ(q2, b))
- [x] `ac` → REJEITA (c ∉ Σ)
- [x] Duas transições para (q0, a) → erro de determinismo
- [x] Transição com estado inexistente → erro
