# Spec 003 — Autômato Finito Não Determinístico (AFN)

| Campo      | Valor |
|------------|-------|
| Status     | ✅ Implementado |
| Módulo     | Módulo 2 do enunciado (AFN) |
| Endpoint   | `POST /api/afn` |
| Aba        | `3. AFN` |

## 1. Objetivo
Definir um AFN (com transições λ), carregá-lo por JSON, executar uma cadeia e mostrar,
a cada símbolo, o **conjunto** de estados em que o autômato pode estar.

## 2. Requisitos (do enunciado)
- [x] Estados, estado inicial, estados finais, função de transição δ: Q × (Σ ∪ {λ}) → P(Q)
- [x] Carregar um autômato por JSON (mesmo formato do AFD)
- [x] Executar uma cadeia
- [x] Mostrar passo a passo (conjunto antes, destinos do "move", conjunto após o fecho-λ)

## 3. Entradas
Igual à [Spec 002](002-afd.md#3-entradas-formato-do-json--o-mesmo-do-arquivo-salvoaberto-na-aba), com duas diferenças:
- O mesmo par (origem, símbolo) **pode** aparecer várias vezes (vários destinos).
- `simbolo` pode ser `"λ"`, `"ε"` ou `""` → transição vazia.

## 4. Regras e validações
- Mesmas validações de Q, Σ, q0, F e estados das transições da Spec 002.
- Símbolo da transição tem que estar em Σ **ou** ser λ.
- Símbolo da cadeia fora de Σ → REJEITA.
- Se o conjunto de estados ativos ficar vazio → REJEITA na hora (todas as ramificações morreram).

## 5. Algoritmo (simulação por conjuntos)
```
atuais = fechoλ({q0})
para cada símbolo s da cadeia:
    se s ∉ Σ: REJEITA
    move    = união de δ[q|s] para todo q em atuais
    atuais  = fechoλ(move)
    registra passo (antes, s, move, atuais)
    se atuais vazio: REJEITA
ACEITA se atuais ∩ F ≠ ∅

fechoλ(C):            // busca em profundidade com pilha
    fecho = C; pilha = C
    enquanto pilha não vazia:
        q = desempilha
        para cada p em δ[q|λ]: se p ∉ fecho: adiciona em fecho e empilha
    retorna fecho
```
Os conjuntos são `TreeSet` (saem sempre em ordem alfabética, fica fácil de ler e testar).

## 6. Contrato da API
Requisição (`exemplos/afn-termina-em-ab.json` — palavras sobre {a,b} que terminam em `ab`):
```json
{
  "estados": ["q0","q1","q2"], "alfabeto": ["a","b"], "estadoInicial": "q0", "estadosFinais": ["q2"],
  "transicoes": [
    {"origem":"q0","simbolo":"a","destino":"q0"}, {"origem":"q0","simbolo":"b","destino":"q0"},
    {"origem":"q0","simbolo":"a","destino":"q1"}, {"origem":"q1","simbolo":"b","destino":"q2"}
  ],
  "cadeia": "babab"
}
```
Resposta (resumida):
```json
{
  "aceita": true,
  "mensagem": "Estados ativos [q0, q2] contêm o(s) final(is) [q2]. ACEITA",
  "caminho": "[q0] -b-> [q0] -a-> [q0, q1] -b-> [q0, q2] -a-> [q0, q1] -b-> [q0, q2]",
  "estadosAtivos": ["q0","q2"],
  "passos": [ {"numero":1,"antes":["q0"],"simbolo":"b","depoisDoMove":["q0"],"depois":["q0"],"restante":"abab"}, "..." ]
}
```
Exemplo com λ: `exemplos/afn-lambda-a-ou-b.json` (L = a* ∪ b*).

## 7. Complexidade
Na montagem de δ, cada inserção de destino mantém o conjunto em ordem. Na execução, os custos do move e do fecho-λ dependem dos estados e transições visitados. O rastro de uma leitura completa de n símbolos também armazena Θ(n²) caracteres nos sufixos. Veja a [análise de complexidade](007-complexidade.md) para os três casos e o custo do fecho-λ.

## 8. Critérios de aceite (testes em `AfnTest`)
- [x] "Termina em ab", `babab` → ACEITA com ativos {q0, q2}
- [x] `aba` → REJEITA
- [x] 1º passo de `ab`: antes {q0}, depois {q0, q1}
- [x] a* ∪ b* com λ: fechoλ({q0}) = {q0,q1,q2}; λ, `aaa`, `bb` aceitas; `ab` rejeitada
- [x] `λ`, `ε` e `""` viram transição vazia
